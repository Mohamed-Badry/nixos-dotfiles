# Assets

This repository contains binary media under `assets/` for local display manager and Plymouth themes.

These files are treated as personal theme assets. Do not assume the MIT license in `LICENSE` applies to third-party images, videos, archives, fonts, or theme media unless their upstream license explicitly allows it.

If you fork or reuse this repository publicly, audit or replace:

- `assets/sddm/bg.jpg`
- `assets/sddm/sword-4k.mp4`
- `assets/plymouth/hexa_retro.tar.gz`

The local Nix derivations in `packages/` expect those paths to exist.
