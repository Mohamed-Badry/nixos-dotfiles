# Assets

`assets/` contains binary media used by local derivations in `packages/`. The MIT license covers code only, not these files.

Before forking publicly, check or replace:

- `assets/sddm/bg.jpg` - SDDM login wallpaper
- `assets/sddm/sword-4k.mp4` - SDDM video background
- `assets/plymouth/hexa_retro.tar.gz` - Plymouth boot theme

The derivations in `packages/` expect these files to exist at those paths.
